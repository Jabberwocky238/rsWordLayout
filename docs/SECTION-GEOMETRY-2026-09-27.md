# 文档页面几何与跨页续排

共享 PTS/LS 路线第 3 片的页面输入和续排部分已接入。后续已补齐
[顺序多栏与连续栏组平衡](COLUMN-FLOW-2026-09-27.md) 和
[物理页镜像边距](MIRROR-MARGINS-2026-09-27.md)；复杂连续节页面组合仍未闭合。

## 页面输入

- `document_from_json` 生成 `LayoutDocument`，保存原始 `main` 块范围与段落范围。
  表格等未布局内容继续计数；正文末尾的 `sectionProps` 是几何元数据，不计为内容遗漏。
- `Engine::layout_document` 按节应用 `pageSize.w/h`、四边 `pageMargins`、gutter。
  `orient` 不再交换已经声明的数字宽高。页眉页脚距离不直接扣正文高度。
- 缺失字段分别回退到本引擎的 A4、1440 twips 页边距。回退来源写入轨迹，
  不把宿主默认值宣称为 Word 默认值。非法几何回退并报告诊断。
- 装订线默认加左边距，`gutterAtTop` 和 `rtlGutter` 分别加上/右边距。
  `mirrorMargins=true` 时忽略 `gutterAtTop`，在物理偶数页交换合成后的左右边距；
  镜像与非零 RTL 装订线的组合保留未验证诊断。
  负上下边距的正文距离取绝对值；页眉页脚重叠尚未布局。
- CLI、SVG、CFFI、WASM 都经过文档几何入口。CLI 的 `--margin`、
  `--page-width`、`--content-width` 依次覆盖所有节；内容宽度优先于左右边距。
  覆盖失败不会留下部分修改，重复调用保留先前未被替换的覆盖项。
- CLI 轨迹新增 `layoutInput`，包含节范围、几何模板、回退字段、显式覆盖和未支持诊断。
  该字段单位是 twips；原轨迹坐标依然是 pt。
  镜像后的实际几何保存在 `Page`，JSON 输出字形位置及多区域页的栏框；单区域 JSON
  不单独暴露版心矩形，不能把模板当成该物理页的实际位置。

## 页面编排

`nextPage` 切换几何并另起页；已经由手动分页打开的空页会被复用。
同几何 `continuous` 保持当前位置。奇偶节按物理页号补空白页，已用合成回归验证；
页码重新编号和 Word 对齐尚未采集。后续镜像合成回归已验证页码标签重启不改变物理相位，
补出的空白页计入镜像序列。

连续节改变几何时，当前页保留旧区域，下次换页采用新几何，并在轨迹中标记这一近似。
这不是对 Word 完整 continuous 行为的结论。外部 `sect-cont-pagesize`、`sect-odd`、
`sect-even` 的最终节实际上未声明 `w:type`，均是默认 `nextPage`，不能用作这些行为的验收。

`LineCursor` 保存未消费的 UTF-16 位置与首行状态。换页后，若正文区域或环绕查询发生变化，
从原段落源流重新生成后续候选行；不重复使用旧页面上已经计算的横向位置。
段前分页、`keepLines` 搬移整段，也先确定新位置再断行。
源段落身份、隐藏文字位置、非 BMP 字符、制表位及换行/分页控制符保持不变。

## 验证与剩余工作

`crates/core/tests/section_geometry.rs` 使用真实 DOCX 解析路径，覆盖字段投影、
原始块下标、不同节宽高、覆盖原子性、跨页续排及控制符源区间。
固定 480 twips 行距的边界容量分别复现既有 margin 报告的 30/30/22/21 行；
这不代表自然行距或所有字体的打印分页已经对齐。

Android 原有 11 份窄路径回放保持 186/186 源行区间匹配，依然使用显式历史元数据假设。
页面几何专项 22 项通过；核心、SVG、CFFI、WASM 现有测试通过。
Mac 修改前后 25 份轨迹的完整 `pages` 数据相同，原有 25 个 FAIL 与 5 个 VOID 不可判
保持原状；新增输入元数据不参与这个几何等价比较。
完整运行记录保存在 `artifacts/section-core-2026-09-27/`。

以上验证数字属于最初的页面几何切片；镜像切片的当前验证见
[镜像页边距](MIRROR-MARGINS-2026-09-27.md)。有效属性、纵向推进/占高分离、顺序多栏
与相同页面几何下的连续栏组平衡均已在后续接入。
