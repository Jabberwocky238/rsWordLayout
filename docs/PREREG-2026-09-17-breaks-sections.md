## 0 这两项此前卡在量具，现在解锁了

V11（分节边界）与 C3（分页符三分）都判不了过，原因是同一个：
`sweep` 里**没有构造标注**，`counting` 只能按字符猜，而 `\x0c` 在 `Range.Text` 里
**分节符与手动分页符同形**。猜不出来就报判不了，整页归行跟着废掉——
vmisc2 丢了三页分页符，vmisc3 丢了分节页。

采集现在写入**经 `verify()` 核对过**的构造标注（`9dc3077`）。
实测在 vmisc3 夹具上：采集包从 `UNDECIDABLE`（25 行可判、3 页全废）
变成 `OK`（28 行全可判、无一页废）。

## 2 预测

### S0 — 每条基线仍落在栅格上

分母 = 采集到的全部基线。第**二十二**次独立检验。

### S1 — 分页符三分：按位置画 0 / 1 / 0 个字形

量具方法 §4 的表：

| 位置 | 应画字形 |
| --- | ---: |
| 行首独占、自成一条行记录 | **0** |
| 紧跟段落标记 | **1**（该行连同段落标记共 +2） |
| 段中，两侧都有文字 | **0** |

三种位置**各三组**。判的是：所有涉及分页符的行记录，
量具的计数模型给出的预期字形数与实测**相符**（行状态 `OK`）。

**判为假的读数**：任何一条涉及分页符的行记录状态是 `COUNT_MISMATCH`。
判不了（`UNDECIDABLE`）单独计，不算失败。
分母 = 这九组涉及的行记录数。

### S2 — 分节边界：跨过 `continuous` 分节那一步，与无分节相比差 **0.24pt**

三对（有分节 / 无分节），每对同设置、同 `exact` 行距。

```
（有分节组第 1→2 段基线差）−（无分节组第 1→2 段基线差）= 0.24pt
```

**判为假的读数**：任何一对不等。分母 = **3**。

> **线索取自已见数据**：这条来自 probe-metrics 作废前的 **n=1** 旧观察，
> 按 §7.5 记为**线索不独立**。本批把 n 从 1 提到 3——
> vmisc3 的 R2 刚教过一课：**三个点一致才勉强算初步，一个点什么都不算**。

## 3 采集前声明的排除项

  （构造标注若因 `verify()` 未通过而没写入，会是这种结果）。
