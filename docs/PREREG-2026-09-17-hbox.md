## 2 预测

### K0 — 每条基线仍落在栅格上

分母 = 采集到的全部基线。第**十六**次独立检验。

### K1 — 右对齐：行尾贴右边界

```
末字形的 x + 末字形的 advance = 523.3pt
```

两边都是**实测量**，右边界是**常数**——不必知道行宽，绕开了字体度量。

四段文本（2 / 8 / 16 / 24 字符）。**判为假的读数**：任何一段不等。分母 = **4**。

### K2 — 两端对齐：**非末行**拉满，末行不拉

两段长文本必然换行。

```
非末行：末字形的 x + advance = 523.3pt
末行　：**不**要求贴右边界
```

**判为假的读数**：任何一条非末行不贴右边界。分母 = 采集到的非末行条数。

> 末行**不判**——这是采集前就声明的范围：两端对齐不拉伸末行是 OOXML 的定义，
> 拿它当判据等于判一条规范条文，不是量 Word。

### K3 — 字距：`w:spacing` 逐字符加在推进量上

同一文本 `abcdefgh` 排四遍，`w:spacing` 分别是 0 / 20 / 40 / 80 半点
（0 / 1 / 2 / 4 pt）。记第 i 与第 i+1 个字形的 x 差为 `Δ(sp, i)`：

```
Δ(sp, i) − Δ(0, i) = sp / 2  pt        对每个 i
```

**字形本身的推进量在相减时消掉**，所以这条也不含字体度量。

**判为假的读数**：任何一个 `(sp, i)` 不等。分母 = 3 个非零字距 × 每段的字形间隔数。

## 3 采集前声明的排除项

- 右对齐组某段换了行 → 该段**判不了**。
- 两端对齐组若只排出一行（没换行）→ 该组**判不了**，因为没有「非末行」。
- 字距组四段的字形数若不相等 → **判不了**（无法逐位相减）。
