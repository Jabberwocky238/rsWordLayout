## 0 为什么要这一份

上一批把问题逼到了这一层：

- **Q0 成立**（240/240）：1/300 英寸（0.24pt）的**显示栅格**已确立；
- **Q1 不成立**（193/228）：「细累加、落位量化」的大方向对，但 **35 处全部差
  恰好一格**，而且可复现（Georgia 13pt 两组都是 10/19）；
- 两种解释已被**算术**排除，不是拟合：**不是读错度量表**（五个族的 `hhea` 与 OS/2
  `winAscent/winDescent` 完全相同，`sTypo` 差约 6%，那会处处出错而不是 228 里错 35），
  **也不是进位规则**（35 处不对的小数部分全 >0.5，可对上的里也有 67 步 >0.5）。

剩下的形状指向：游标不在**实数**上累加，而在某个**比 0.24pt 细的整数单位**上走。
这一份判那个单位。

## 1 容差

**0.0000pt**，逐位相等。唯一例外：PDF 读数的十进制舍入取 **1e-6 pt**，
仅吸收浮点表示，不吸收任何真实差异。

## 2 模型

记 `grid = 0.24pt`，`quantize(v)` 为四舍五入到 `grid`，
`natural = (hhea.ascender + |hhea.descender| + hhea.lineGap) / upem × 字号pt`。

设游标单位为 `u`（点）。每行的步长**先取整到 `u`**，再按整数步累加，
最后**落位时**量化到显示栅格：

```
step(u) = 四舍五入(natural / u) × u
预测第 n 条基线 = quantize(b₀ + n × step(u))          n = 1 … N−1
```

`b₀` 取该组**实测的第一条基线**——首行那一项上一批没判成（Q2 9/12），
在这里把它当已知条件给出去，好让本批只判单位本身。**一条预测只判一件事。**

`u = 0` 约定为「不取整、走实数」，即上一批 Q1 的模型。

## 3 预测

### R0 — 每条基线仍落在栅格上

**判为假**：任何一条基线的 y 不是 0.24pt 的整数倍。分母 = **762**。

五个族（Chalkduster / Big Caslon / Andale Mono / Ayuthaya / Krungthep）与前两批
没有一个重合，`upem` 分别是 905 / 1000 / 2048 / 2100 / 2560，所以这是第三次
**独立**检验，不是同一批证据再数一遍。

### R1 — 单位是 twip（1/1440 英寸 = 0.05pt）

**这是本批的点预测。** Word 的文档模型一向以 twip 为整数单位，所以先判它。

```
u = 0.05
```

**判为假的读数**：任何一步的实测基线 ≠ 预测值。分母 = **752**。

### R2 — 候选清单（**采集前钉死，不许增删**）

| 记号 | 单位 | 点 |
| --- | --- | ---: |
| U1 | 1/1440 英寸（twip） | 0.05 |
| U2 | 1/2880 英寸（半 twip） | 0.025 |
| U3 | 1/7200 英寸 | 0.01 |
| U4 | 1/600 英寸 | 0.12 |
| U5 | 1/1200 英寸 | 0.06 |
| U0 | 实数（不取整） | — |

**通过的门槛是 752/752 逐位相等**，不是「谁分最高」。按最高分选模型就是拟合；
这里要么全中，要么不算。三种结局**采集前**就写死：

- **恰好一个通过** → 在本批范围内，它就是那个单位；
- **一个都不通过** → 候选清单里没有正确答案（或模型的**形状**不对，
  即「先取整步长再整数累加」这个假设本身错了）；
- **不止一个通过** → 本夹具**分不开**它们，报出是哪几个，并说明夹具无力，
  **不许挑一个当结论**。

夹具的鉴别力**采集前**已核过（只用字体度量与夹具本身，不用任何读数）：
80 步里，各候选与 U0 给出不同基线的步数在 **20 ~ 78** 之间，两两之间也分得开。
唯一的例外是 **Andale Mono 6pt**：它的自然行高正好 6.7500pt，是每个候选单位的
整数倍，所有候选在它上面同解。**留着它是故意的**——它判不出单位，但若连它
也出现不对，那说明错的不是单位，是模型的形状。

## 4 采集前声明的排除项

某组的行**没有全部落在同一页上**时，该组的 R1 / R2 读数**判不了**，
记入分母但不算通过（§8 的口径排除，不是放宽容差）。累加从每页顶重新开始。
夹具已按各字体各字号算过能排几行并留了一行余量，正常排版下不该触发。
