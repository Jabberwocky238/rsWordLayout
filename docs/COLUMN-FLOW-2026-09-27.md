# 顺序多栏排版

共享排版器已读取节 `columns`，将同一个段落断行器续排到各栏。支持等宽栏、显式不等宽栏、
自动换栏、独立栏断及 `nextColumn` 分节；最后一栏用尽后才换物理页。
本片没有实现末页栏平衡、同页混合栏组或从右到左的栏顺序。

## 输入与区域

`LayoutSection.columns` 保存 `ColumnLayout`；`areas(body)` 给出按读序排列的栏框。
等宽栏从正文宽度扣除非末栏间距后分配，整数 twips 余数从左到右分配。这是宿主取整策略，
不是新测的 Word 舍入规则。显式栏保留每栏宽度和间距，不把右侧剩余空白缩放进栏宽。

原始列声明、有效几何和派生栏框写入 `layoutInput.sections[].columns`。非法数量、宽度、
间距或无法放进正文的组合会记录诊断并退回单栏，原声明仍保留。CLI 改页宽/边距时重新验证
所有栏框；覆盖会破坏栏几何则整体拒绝，不留半更新状态。

缺省 `equalWidth=true`、`num=1`、等宽栏间距 720；这些输入默认不表示所有 Word 宿主
的行为都已实测。不等宽栏由显式列表决定，忽略冲突 num 时写出诊断。分隔线、竖排和
RTL 顺序尚未实现，不能把读取它们称为支持相应排版。

## 流转规则

私有 `FlowRegions` 记录当前栏、下一栏和下一物理页的区域。自动溢出与 keep 搬移以
“当前栏是否为空”判断，避免第二栏为空时被第一栏已有内容误导，进而反复跳过空栏。
显式页断和 `pageBreakBefore` 以物理页为单位，跳过尚未使用的栏。

换栏只重置纵向游标，页内行号继续递增；只有物理换页才将行号归零。区域改变后从原 UTF-16
游标重新断行，并重新查询环绕区。keepLines、keepNext 和 widowControl 读取真实后继区域；
预检搬移整链时还预测再下一个区域，避免不等宽栏把尾部孤行检查放在错误的宽度上。

栏断是独立 `FlowBreak::Column`。它消费一个源码元，栏断后的段落标记留到下一栏/页，
不套用打印视图页断与段落标记合并的规则。`nextColumn` 截断 keepNext 链；前一个显式
控制已经开启空区域时，不再重复推进。连续节改变栏配置时，当前物理页沿用旧栏组，
下一物理页使用新配置，并报告尚未支持同页混合栏组/平衡的限制。

## 输出与证据

`Page` 和 `PaintPage` 保存栏框以及按页内行号索引的栏归属；绘制记录按真实行号查归属，
不通过 x 坐标或基线猜测。多栏 JSON 页额外输出 `columns` 栏框（pt）和各行 `column`。
缺失或越界归属输出 null。单栏页保持原 JSON 形状，栏断终止符单独记录为 `COLUMN_BREAK`。
栏断的一个控制字形沿用旧约定，尚无原始字形读数确认；它不能成为 Word 字形计数通过的依据。
量具源模型也独立标注 `COLUMN_BREAK`，计数保留 `UNKNOWN_MARK / UNDECIDABLE`，
不再借页断规则给出零字形通过。同基线行只有确定在同栏时才检查 run 拆行；
已声明多栏但缺少有效栏归属时不可判，不从字形坐标猜测归属或栏顺序。

报告来源：`word_analyse/reports/rsword-diff/columns.md` 与
`word_analyse/findings/pagination-path.md`。输入由本机 DOCX 的 XML 复查：

| 输入 | 本轮回测 | 证据范围 |
| --- | --- | --- |
| twocol64 | 1 页，32+32 行，栏宽 4873 twips | 页数、两栏容量与宽度来自旧报告 |
| twocol65 / twocol70 | 2 页 | 页数来自旧报告；末页顺序填充不代表已测平衡规则 |
| br-column | 1 页，11+6 行 | 旧报告裁剪带支持栏断后段落标记另占一行 |
| br-column-one | 2 页，每页 11、6 行 | 同上，单栏栏断推进到下一物理页 |

twocol 系列纸张 11906×16838、四边距 720、栏间距 720、行距 exact 480。
栏框为 `(720,720,4873,15398)` 与 `(6313,720,4873,15398)`。
每段 32 个 UTF-16 码元；64 行用完第一页时下页首 CP=2048。栏断样本的 CP=341 切点
由输入和报告推导，未取得原始 CP 读数。本机未找到这些同名原始日志，没有新增 Word 采集。

## 验证与剩余工作

`column_input` 验证原始 JSON/实际 DOCX 投影、无效输入、默认值与原子覆盖；
`column_flow` 验证等宽/不等宽区域、源区间连续、页内行号、控制符与段落保留，
并提供本机 Calibri 的旧夹具回测；`column_records` 验证绘制到轨迹的栏框和归属。
运行产物保存在 `artifacts/columns-2026-09-27/`。

本轮 Rust 常规回归 484 项通过，随后补齐的列输入 17 项通过；多栏专项含实际 Calibri
回测共 12 项通过，相关 crate 全目标 Clippy `-D warnings` 与 workspace check 通过。
Python 量具 268 项通过。额外 4000 组组合检查保持源区间完整、页内行号唯一和栏归属有效。
Android 既有窄路径保持 186/186 条件匹配；Mac 25 份有效轨迹页面内容与前一切片一致，
既有 25 包 FAIL、5 包采集无效不可判未变。本机打印夹具的命令、输入/二进制/字体哈希
和实际轨迹保存在 `print-fixtures/manifest.json` 及各案例目录，未冒充新的 Word 采集。

后续仍须完成末页栏平衡、连续节混合栏组、RTL 顺序和分隔线，以及独立 Word 原始证据。
当前测试通过只证明上述顺序流切片，不能据此宣称全部 PTS 多栏规则已实现。
