## 0 为什么判这个

a-form 判掉了「固定比例」：不存在跨全部 16 个 `w:line` 的单一 k
（`line=206` 要求 k ∈ [0.801942, 0.803883)，`line=210` 要求 k ≥ 0.805714，不交）。

但失败**有方向**：各组容许的 k **随 L 增大而增大**。固定比例给不出这个走向，
**固定距离**给得出。若基线在行底上方固定 `d` 格：

```
A = 300 + L − d          ⟹   c(n) = ⌊300 + (n+1) × L − d⌋
k = 1 − d / L            随 L 递增，正是实测的方向
```

`d` 与 k 一样不含字体量，与 font-free / size-free 是一路的。

**线索取自已见数据**（a-form 的失败走向），按 §7.5 记为**非独立检验**。
能做的是：换十六个全新的 `w:line`，**跨度放大一倍**，且只判存在性。

## 1 夹具为什么把跨度拉大

固定比例与固定距离的差别随 `L` 的跨度放大。a-form 的 206 ~ 308 twips
只有 **1.5 倍**跨度，本批 150 ~ 460 twips 是 **3 倍**（7.5 ~ 23pt）。
`w:line` 与前六批**无一重合**。

## 2 容差

**0.0000pt**。`d` 的约束区间用**有理数**算，不沾浮点。

## 3 预测

### D0 — 每条基线仍落在栅格上

分母 = **160**。第**十四**次独立检验。

### D1 — 点预测：**存在**常数 d，使 `c(n) = ⌊300 + (n+1) × L − d⌋`

每条基线把 d 限到 `[(n+1)·L + 300 − c − 1, (n+1)·L + 300 − c)`，全部取交集，
**非空即成立**。

**不是拟合**：不挑「最好的 d」，只问交集空不空；且 d 是**跨全部 16 组共享的
一个常数**，十六种行高必须被同一个 d 解释。

**判为假的读数**：交集为空。分母 = **160**（按顺序累积，报第一次变空前满足了多少条）。
