## 0 这一批不判 Word，判**量具**

量具方法 §5 给的噪声底是 **0.0000pt**，本项目十七批的容差都按它取 0。
但两批横向读数里，本该精确成立的关系稳定差一点点：

| 批次 | 多数读数的偏离 |
| --- | ---: |
| hbox（K3） | **0.0005 pt** |
| hbox2（M2） | **0.000384 pt** |

**量级一致、方向一致、跨夹具重现。** 那可能根本不是 Word 与预测的差，
而是**读数本身的量化**。若真如此，「容差 0」在亚千分之一磅这一层就不成立，
而**所有横向判据都建在它上面**——包括已经判掉的 H3b / H3c / H3d / H4a。

所以先回头量量具自己。

## 1 办法：造一批**本该逐位相同**的读数

不需要任何模型，只需要「相同的输入应当给出相同的输出」：

1. **行间**：同一段文本 `mnopqrst` 重复 **20 行**，同字体同字号、
   `exact` 行距（已确立与字体字号无关）、左对齐、零缩进。
   第 i 个字形的 x 在 20 行之间应当**完全一样**。
2. **行内**：一行里把 `xy` 重复 **12 遍**。
   每一遍内部的间隔（x 与 y 之间）应当**完全一样**。

三个字体各做一遍，看噪声是否与字形有关。

## 2 容差

**先按 0.0000pt 判**（与此前一致），**同时报出实测的最大偏差**——
后者才是这一批真正要的数。

## 3 预测

### N1 — 行间：同一文本各行的字形 x 逐位相同

**判为假的读数**：任何一行的第 i 个字形 x ≠ 第 0 行的。
分母 = 3 组 × 19 行 × 每行字形数。

### N2 — 行内：同一字符组各遍的内部间隔相同

**判为假的读数**：任何一遍的内部间隔 ≠ 第 0 遍的。
分母 = 3 组 × 11 遍。

## 4 这一批怎么读

- **两条都成立** → 噪声底确实是 0，此前十七批的容差站得住，
  hbox / hbox2 的那 0.0004 是**真实差异**，得另找原因。
- **有一条判假** → 噪声底**不是 0**，实测最大偏差就是它。
  此前所有横向判据都得按这个底重读，而 §5 那句「噪声底 0.0000pt」要改。

**无论哪种，都不回头改已判批次的判定**——那些批次按它们自己的预注册判过了。
要改的是**往后**怎么取容差，以及给已判结论加上「在什么噪声底之下」的限定。
