## 2 预测

### R0 — 每条基线仍落在栅格上

分母 = 采集到的全部基线。第**二十一**次独立检验。

### R1 — 分节边界：跨过 `continuous` 分节那一步，比常规多**一格**

```
（有分节组的第 1→2 段基线差）−（无分节组的第 1→2 段基线差）= 0.24pt
```

**判为假的读数**：不等。分母 = **1**。

> **线索取自已见数据**：「分节边界多一格」是 probe-metrics 作废前的旧观察，
> 而且只有 **n=1**。按 §7.5 记为**线索不独立**，成立也只算初步。
> 分母只有 1 也是弱项——本批只能说「那个 n=1 的观察在一个新实例上重不重现」。

### R2 — `atLeast` 的首行比 `exact` 高 **3 格（0.72pt）**

三个新的 `line` 值（340 / 460 / 580 twips，与 vmisc 的 400/520/640、第一版的 360/440/560 均不重合）。

```
exact 首行格数 − atLeast 首行格数 = 3
```

**判为假的读数**：任何一个 `line` 不等于 3。分母 = **3**。

> 「3 格」取自 vmisc 的 P3（那批三个 `line` 值差都恰好 3 格），
> 属**已见数据**，按 §7.5 记为**线索不独立**。本批换了三个新 `line` 值。

### R3 — 字符缩放：相邻字形 x 差按百分比缩放

`w:w` = 100（对照）/ 120 / 180 / 66，与第一版的 150/200/50 不重合。记第 i 与 i+1 个字形的 x 差为 `Δ(sc, i)`：

```
Δ(sc, i) = Δ(100, i) × sc / 100
```

**判为假的读数**：任何一个 `(sc, i)` 不等。分母 = 3 个非 100 的缩放 × 每段间隔数。

## 3 采集前声明的排除项

- 某组没有排出预期行数 → 该组**判不了**。
- 缩放组各段字形数不等 → **判不了**（无法逐位相比）。
- **含 `w:sectPr` 的段落若使整页归行判不了**（vmisc2 在分页符上就这样），
  该组**判不了**，不算失败。

### 5.1 第一版为什么作废

第一版沿用了 vmisc2 的申请列表，把 `Times New Roman` 也**申请**了。
但本批夹具里每个段落都有可见 run，**没有 vmisc2 那种「只含 `w:br` 的空段落」**，
Word 根本用不到默认字体。于是 F-B 触发，而**账外字体是空列表**——
触发的是另一半：**申请的字体没有出现**。

这暴露了核查逻辑的一个真缺陷：**「申请了却没出现」与「出现了不该出现的」是两回事**。
前者对可选的回退字体根本不适用——用不用得到，取决于夹具里有没有那种段落。

**已修**：`font_substitution_check` 加了 `optional_families`，
「必须出现」与「允许出现」分开，只有前者缺席才报替换。
本批因此**只申请 `Luminari`**，不再需要可选项。

第一版**照记作废**，`w:line` 与 `w:w` 的取值也全换了。
判据脚本在算 R0–R3 之前就短路，`predictions` 是空的，所以重采不构成「看了结果再调」。
