# 量具能测什么，已经测到哪儿

量具直接读到的只有四样（方法 §1 / §2）：**每个字形画在哪里**（`glyphOrigin`）、
**推进量**、**字形数**、**字体名**。页数与行划分来自行号扫描。
所有「规则」都只能从这四样推出来——推不出来的，就不在这份清单里。

每一行的「状态」只有三种：**已确立**、**已排除**、**未决**。
「看着像」不算状态。

## 范围外（量具测不了，别放进清单）

- 表格、脚注、文本框里的排版（§5：8.5% 的字形不在行划分覆盖内）
- 行盒的顶/高（§1：PDF 里不能唯一确定，只能测字形原点）
- Windows 侧的一切（§6.6：与 Mac 是两套字体度量，本项目全部读数都是 Mac）
- 制表位、自动编号、合成字体、CJK 断行（§4 明说在范围外）

## 顺序

先做**能把变量分离开**的：`w:lineRule=exact` 把「字体度量」从行距里摘出去，
于是 V8 的一部分同时也是对**累加机制本身**的检验——那是 V7 一直绕不过去的东西。
