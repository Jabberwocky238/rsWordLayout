### Q1 — 抬升量**量化到栅格**

```
y_normal − y_raised = quantize(val / 2)        quantize 到 0.24pt，半数进位
```

（第一版作废于 F-B，见 §5.1）。刻意让一半落在整格上、一半落不上：

| `val` | pt | 格 | 整格？ |
| ---: | ---: | ---: | --- |
| 10 | 5.0 | 20.833 | **否** |
| 14 | 7.0 | 29.167 | **否** |
| 24 | 12.0 | 50 | 是 |
| 26 | 13.0 | 54.167 | **否** |
| 48 | 24.0 | 100 | 是 |

**判为假的读数**：任何一个不等。分母 = **5**。

> 半数进位这个方向取自 vmisc 的读数（`val=6` 实测 3.12 = 13 格，向上），
> 属**已见数据**，按 §7.5 记为**线索不独立**。但取值全换了，

### Q2 — 同一行内，不同字号**共用一条基线**

每行三段 run：小字号、大字号、小字号。三种字号组合
（10/20pt、13/26pt、8/30pt）。

```
同一行内所有字形的 y **完全相同**
```

**判为假的读数**：任何一行内有两个字形 y 不同。分母 = **3**。

### Q3 — 分页符按位置画 0 或 1 个字形

三种位置各一组（§4 的三分）：**独占一段** / **紧跟段落标记** / **段中**。

判的是**量具的计数模型与实测字形数对得上**：`wordmodel` 给出的每条行记录
状态都是 `OK`（不是 `COUNT_MISMATCH`，也不是判不了）。

**判为假的读数**：任何一条涉及分页符的行记录状态不是 `OK`。
分母 = 这三组涉及的行记录数。

### 5.1 为什么要申请 `Times New Roman`

第一版夹具采集后作废于 F-B：PDF 里出现 `TimesNewRomanPSMT`。查清楚了——
**Times 只出现在空格字形上，而且只在「只含 `w:br` 的那个段落」的段落标记处**。
那种段落没有任何可见 run，Word 就拿**默认字体**画它的段落标记，
`w:pPr/w:rPr` 里指定的字体管不住。

**那一组不能改。** 「整段只有一个分页符」正是 §4 三分里的第一种；
在它前面加可见文字，它就变成第二种「紧跟段落标记」，三分塌成两分。

所以改的是**申请清单**：把 `Times New Roman` 列进去，理由就是上面这条——
**它是 Word 画空段落标记时必然会用的字体，不是替换**。

这不是放水：F-B 仍然会报**任何其他**账外字体。
放宽的只是一个已经查清原因的、可预期的名字。

**第一版的作废照记**，不追认。判据脚本在算 Q1/Q2/Q3 之前就短路，
`predictions` 是空的，所以换取值重采不构成「看了结果再调」。
