## 2 预测

### Q0 — 每条基线仍落在栅格上

分母 = 采集到的全部基线。第**二十**次独立检验。

### Q1 — 抬升量**量化到栅格**

```
y_normal − y_raised = quantize(val / 2)        quantize 到 0.24pt，半数进位
```

`w:position` 取 **6 / 18 / 24 / 30 / 48** 半点。刻意让一半落在整格上、一半落不上：

| `val` | pt | 格 | 整格？ |
| ---: | ---: | ---: | --- |
| 6 | 3.0 | 12.5 | **否** |
| 18 | 9.0 | 37.5 | **否** |
| 24 | 12.0 | 50 | 是 |
| 30 | 15.0 | 62.5 | **否** |
| 48 | 24.0 | 100 | 是 |

**判为假的读数**：任何一个不等。分母 = **5**。

> 半数进位这个方向取自 vmisc 的读数（`val=6` 实测 3.12 = 13 格，向上），
> 属**已见数据**，按 §7.5 记为**线索不独立**。但取值全换了，
> 而且三个非整格值一起判，不是拿一个点凑。

### Q2 — 同一行内，不同字号**共用一条基线**

每行三段 run：小字号、大字号、小字号。三种字号组合
（10/20pt、13/26pt、8/30pt）。

```
同一行内所有字形的 y **完全相同**
```

**判为假的读数**：任何一行内有两个字形 y 不同。分母 = **3**。

### Q3 — 分页符按位置画 0 或 1 个字形

三种位置各一组（§4 的三分）：**独占一段** / **紧跟段落标记** / **段中**。

判的是**量具的计数模型与实测字形数对得上**：`wordmodel` 给出的每条行记录
状态都是 `OK`（不是 `COUNT_MISMATCH`，也不是判不了）。

**判为假的读数**：任何一条涉及分页符的行记录状态不是 `OK`。
分母 = 这三组涉及的行记录数。
