## 2 预测

### P1 — 行高 = 自然行高四舍五入到 0.24pt 栅格

对每个「字号扫描」与「字体扫描」探针，令

```
natural = (hhea.ascender + |hhea.descender| + hhea.lineGap) / upem × 字号pt
预测行距 = round(natural / 0.24) × 0.24
```

**判为假的读数**：任何一个探针的实测行距 ≠ 预测行距。
（一个探针给两个行距读数，两者本身也必须相等；不等即该探针判不了，记入分母但不算通过。）

分母：9 个字号 × 2 + 4 个字体 × 2 = **26** 个行距读数。

### P2 — 首行基线 = 行高 − 量化后的 descent

```
预测基线偏移 = 预测行距 − round((|hhea.descender| / upem × 字号pt) / 0.24) × 0.24
```

基线偏移指「正文区顶到该页第一条基线」，正文区顶 = 上边距 = 72pt。

**判为假的读数**：任何一页的实测首行基线偏移 ≠ 预测值。
分母：采集到的页数（每页一个读数）= **27**。

分母是页数，所以夹具让**每个探针组独占一页**（`w:pageBreakBefore`，段落属性，
不产生字符，不碰 §4 的分页符三分）。不这么排，全文只有 2 页，P2 就还是 n=1——
和它要解决的问题一模一样。

**采集前声明的排除项**（§8 的口径排除，不是放宽容差）：某页首行**自身**带
`w:position` 或 `w:vertAlign` 时，该页不判。那两样改的是行高本身，归 G-9 与 P4；
拿它们判 P2 等于把别的题的错算到这题头上。按**行**排除，不按**组**排除——
每组第一段都是普通行，所以正常排版下这条一次也不该触发；
真触发了说明分页跟设计的不一样，那本身就该看见，所以它会原样打印，不是悄悄少算分母。

### P3 — 上下标字号 = 0.66 × 正文字号，**不量化**

```
预测字号pt = 0.66 × 正文字号pt
```

**这一条刻意不加量化。** 12pt 下 0.66×12 = 7.92pt 恰好也落在栅格上（33 × 0.24），
两种读法分不开；10pt 下 0.66×10 = 6.6pt，而量化会给 6.72pt——**两者在这里分岔**，
所以这份夹具能判。

**判为假的读数**：任何一个上标或下标探针的实测字号 ≠ 0.66 × 正文字号（±1e-6）。
分母：3 个字号 × 2 种 = **6**。

### P4 — 上标升 0.34 em、下标降 0.08 em，**量化到栅格**

```
预测上标抬升 = round((0.34 × 正文字号pt) / 0.24) × 0.24
预测下标下沉 = round((0.08 × 正文字号pt) / 0.24) × 0.24
```

与 P3 相反，这一条**加量化**：纵向的一切都落在栅格上（W-1，56/56），
所以纵向量应当量化，横向的字号不必。12pt 下两种读法都给 4.08 / 0.96，
10pt 下量化给 3.36 / 0.72 而不量化给 3.40 / 0.80——**在这里分岔**。

**判为假的读数**：任何一个探针的实测基线差 ≠ 预测值。分母：**6**。

### P5 — 分节边界后那一行，行距比常规多**正好一格**（0.24pt）

```
预测 = 常规行距 + 0.24
```

「分节边界后那一行」指：`w:sectPr` 所在段落的**下一段**的基线，减去该段落自身的基线。

**判为假的读数**：两个分节探针中任何一个的实测差 ≠ +0.24pt。分母：**2**。

> 这条是从 **n=1** 提出来的，本身就是它的第一次独立检验。
> 两个实例都中才算初步成立，且结论仍只覆盖 `continuous` 型分节。

## 3 探索项：**不作预测**

### G-9 — 含抬升 run 的行，行高变多少

**这一项不给预测，只采数。** 理由：现有唯一实例（12pt，`w:position=8`，
行距 13.68 → 18.0pt，多 4.32pt）**对不上我试过的每一个模型**——
`quantize(ascent + rise)` 给 17.76、先量化 rise 再加也给 17.76、向上取整又会
把常规行距算成 13.92（实测 13.68）。

从一个点凑一条规则出来，那是拟合不是预测。所以这一项的目的是**把 n 从 1 提到 6**
（`w:position` 取 2/3/4/6/8/12 半点），**采完之后**再看形状。

**纪律**：采完若能形成规则，它按 §7.5 标「回测」，**不当独立检验**；
要确立它还需要再来一份夹具。
