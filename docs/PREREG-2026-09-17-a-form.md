## 1 要判的形式，以及它是怎么来的

`exact` 下 `step` 就是行高的格数 `L = w:line × 10 / 48`。若基线固定落在行内的
某个**比例** k 处：

```
A = 300 + k × L        （300 格 = 72pt = 正文区顶）
c(n) = ⌊300 + (k + n) × L⌋
```

k 的物理意义是**基线在一行之内的相对高度**——一个纯排版常数，不含任何字体量，
与前两批「字体字号都不参与」是一路的。

**线索的来源要说清楚。** 这个形式不是凭空来的：把前三批（shift-floor /
font-free / size-free）的首行格数减去 300 再除以 L，八组都落在 **0.79 ~ 0.81**
之间。那是**已见数据**，所以本批按 §7.5 记为**「线索取自已见数据」**——
成立只算初步，但检验用的是**十六个全新的 `w:line` 值**，且本批**不预测 k 的值**，
只判「存不存在这样一个 k」。

## 2 容差

**0.0000pt**，逐位相等。k 的约束区间用**有理数**算，不沾浮点。

## 3 预测

### Z0 — 每条基线仍落在栅格上

分母 = **160**。第**十三**次独立检验。

### Z1 — 点预测：**存在**常数 k，使全部基线满足 `c(n) = ⌊300 + (k+n) × L⌋`

**怎么判**：每条基线把 k 限到 `[(c−300)/L − n, (c+1−300)/L − n)`。
把 160 条的区间全部取交集，**非空即成立**。

**这不是拟合**：不挑「最好的 k」，只问交集空不空。而且 k 是**跨全部 16 组共享的
一个常数**——16 个不同的 `w:line` 必须被同一个 k 解释，这比每组各拟一个参数强得多。

**判为假的读数**：交集为空。分母 = **160**（按顺序累积交集，
报出第一次变空之前满足了多少条）。

## 8 结论

采集包：`captures/a-form-2026-09-17/`。Word for Mac，16 页，480 字形，
四条证否条件一条都没触发。

| | 判据 | 结果 | |
| --- | --- | ---: | --- |
| **Z0** | 每条基线落在栅格上 | **160 / 160** | **成立** |
| **Z1** | 存在常数 k 使 `c(n) = ⌊300 + (k+n) × L⌋` | 113 / 160 | **不成立** |

### Z1 不成立：没有单一的比例常数

第一组（`line = 206`）把 k 限到 **[0.801942, 0.803883)**，
而第二组（`line = 210`）要求 k ≥ **0.805714**。两者不交，交集在第 12 条基线上就空了。

**每一组内部都自洽**——各组都能找到自己的 k；不成立的是「同一个 k 解释所有行距」。
所以 k 随 `w:line` 变，而「k 随 line 变」等价于「A 是 line 的任意函数」，
那句话没有信息量。**这个形式判假。**

### 探索性（§7.5 标「回测」，**不当独立检验**）

失败的形状是有方向的：各组容许的 k 随 `L` 增大而增大
（206 → 约 0.803，210 / 214 / 238 → 约 0.807 起）。

**固定比例**给不出这个走向，**固定距离**给得出：若基线在**行底上方固定 d**，则

```
A = 300 + L − d        ⟹    k = 1 − d / L
```

L 越大 k 越大，正是实测的方向。而且 d 与 k 一样不含字体量，
与 font-free / size-free 是一路的。

**到此为止，不再往下凑。** 这个形式要成立，得有它自己的预注册和自己的夹具。
